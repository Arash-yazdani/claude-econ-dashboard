# Decision needed — the charter's competitive score (9.3/10)

**Status:** CLOSED — Option B (withdraw). Decided 2026-08-21; erratum SENT to Bruce and ACKED
2026-08-21 (reported by Arash). The 9.3/10-vs-7.4 competitive score is withdrawn from the record;
the charter now stands amended by two acked errata (publish time, competitive score), with the
signed document itself untouched. No open charter items remain.
**The problem:** all three signed Charter revisions state the product scored **9.3 out of 10
against alternatives, best competitor 7.4, across 29 measures**. No workpaper, scoring sheet,
measure list, or competitor set exists anywhere in the repo (searched 2026-08-17 audit + again
2026-08-20). A signed client document carries a precise quantitative claim with no evidence
behind it — the exact "silent staleness is the trust failure" class the PRD warns about, and
the kind of unsupported number Bruce (a 30-year process auditor) is most likely to probe.

## The two honest options

**A. Evidence it.** Reconstruct the comparison for real: define the 29 measures, pick the
competitor set (e.g. a FRED dashboard, a news app's markets tab, a Bloomberg-lite), score
honestly, publish the workpaper in docs/. Risk: an honest re-score probably does NOT reproduce
9.3-vs-7.4, which then requires a charter correction anyway — with more egg on it.
**Effort:** hours, and it produces a marketing artifact of real value only if the method is
defensible.

**B. Withdraw it.** A one-paragraph erratum (same channel as the publish-time erratum Bruce
just approved): the score was a directional judgment, not a measured comparison; the charter
should not present it as data; it is withdrawn, and the product's actual measured evidence
(61 days of publishes, zero validator failures, 100% O5/O8, reconciliation matched) stands in
its place. **Effort:** minutes. Cost: admitting a number in a signed doc was unsupported —
which the time erratum already set a good precedent for.

## Recommendation

**B**, for the same reason the time erratum worked: Bruce rewards candor about process and
punishes unsupported precision. Option A manufactures evidence after the claim, which an
auditor reads as backfilling. If a competitive comparison is genuinely wanted, do it fresh,
as its own project, with the method stated first.
