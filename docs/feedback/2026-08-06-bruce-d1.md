But three verified defects make his instinct correct for reasons he did not give:

### A · The headline is a few-shot echo, not a narration

**99 of 109 published headlines are byte-identical to EXAMPLE 1 in `prompt.py:113`** —
*"Soft landing continues, driven by a steady job market."* — punctuation included. On a quiet day
the model retrieves the example verbatim instead of writing.

This, not the classifier, is the root of SCRUM-91's sameness. An earlier reading of that ticket
attributed it to a stable regime being faithfully narrated; that was wrong.

### B · `soft_landing` is both a real rule and the catch-all `else`

`classifier.py:133-134` is the genuine rule; `:137-138` is the fallthrough, and both emit the same
label. Verified by execution on 2026-08-06:

```
GDP  -2.0%, unemp 4.2, core 2.57  ->  soft_landing   (with two confident quotable numbers)
GDP -19.0%, unemp 4.2, core 2.57  ->  soft_landing
unemp 6.2   (the 2014-15 shape)   ->  soft_landing
ALL readings None                 ->  soft_landing
```

A depression publishes *"Soft landing."* Missing data publishes *"Soft landing."*
`plausibility.py:27-28` returns `True` for `None` by design, so nothing upstream stops it.

`docs/classifier/regime-classifier-v1.1-proposal.md:16` already logs this as **Finding A**
(🔴 correctness) — D9-accepted precedent, not a new argument.

Consequence for the 12-year back-test: `unemp 6.2` reaches the `else`, so **an unknown share of
the reported 37% `soft_landing` is fallthrough, not a matched rule.** That share is not measurable
until the classifier records which branch fired (plan item W1). Bruce should see the number before
he signs anything.

### C · Driver ranking is inverted for conjunctive rules

`_soft_landing_candidates` (`classifier.py:174-176`) scores distance *inside* the band, and
`_rank_drivers` sorts `reverse=True` (`:196-199`). On 2026-08-06 unemployment slack `0.800`
outranks core CPI `0.434`, so the card names the **least** binding constraint as the driver.

Deferred to the O3 recalibration — it is a ranking question, not a labelling one.
